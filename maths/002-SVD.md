# SVD (Singular Value Decomposition)

# 🎯 SVD란?

SVD(Singular Value Decomposition)는 어떤 행렬이든 다음과 같이 세 개의 특별한 행렬로 분해하는 방법이다.

```math
A = U \Sigma V^T
```

여기서:

- $(A$): 임의의 $(m \times n$) 행렬
- $(U$): 출력 공간(output space)의 방향을 나타내는 직교 행렬
- $(\Sigma$): 각 방향의 중요도(크기)를 나타내는 대각 형태의 행렬
- $(V$): 입력 공간(input space)의 중요한 방향을 나타내는 직교 행렬

---

# 🧠 각 행렬의 역할

SVD는 실제로 다음 순서로 동작한다.

```math
Ax = U \Sigma V^T x
```

즉 오른쪽부터 적용된다.

---

## 1️⃣ $(V^T$)

입력 좌표계를 데이터가 가장 잘 퍼진 방향으로 회전시키는 변환

```math
x \rightarrow V^T x
```

즉:

- 입력 공간의 축을 재정렬
- 데이터의 중요한 방향(principal direction)을 찾음

---

## 2️⃣ $(\Sigma$)

각 방향으로 얼마나 늘리거나 줄일지를 결정하는 스케일 변환

```math
V^T x \rightarrow \Sigma V^T x
```

- 큰 특이값 → 중요한 방향
- 작은 특이값 → 중요하지 않거나 노이즈 방향

---

## 3️⃣ $(U$)

변환된 결과를 최종 출력 방향으로 회전시키는 변환

```math
\Sigma V^T x
\rightarrow
U \Sigma V^T x
```

즉:

- 출력 공간에서 결과 방향 결정
- 최종 형태와 방향을 완성

---

# 🎯 전체 흐름 요약

```math
입력 공간 회전
\rightarrow
축 방향 스케일 변화
\rightarrow
출력 공간 회전
```

즉:

```math
회전
\rightarrow
늘리기/줄이기
\rightarrow
다시 회전
```

이 세 단계로 어떤 선형변환이든 표현할 수 있다는 뜻이다.

---

# 🍕 피자 비유로 이해하기

행렬 $(A$) 를 피자 반죽을 변형시키는 과정이라고 생각해보자.

---

## $(V^T$)

반죽을 작업하기 좋은 방향으로 먼저 돌려놓는다.

---

## $(\Sigma$)

반죽을 가로/세로 방향으로 각각 다르게 늘리거나 줄인다.

예:

- 가로 3배
- 세로 0.5배

---

## $(U$)

완성된 반죽을 마지막 원하는 방향으로 다시 돌려 놓는다.

---

즉:

```math
회전
\rightarrow
늘리기/줄이기
\rightarrow
다시 회전
```

이 세 단계만으로 어떤 모양의 변형도 표현할 수 있다.

---

# 🎨 기하학적으로 이해하기

2차원 단위 원(unit circle)을 생각해보자.

초기 상태:

```text
     *****
   **     **
  *         *
  *         *
   **     **
     *****
```

---

## Step 1 — $(V^T$)

원을 먼저 회전시킨다.

하지만 원은 회전해도 여전히 원이다.

```text
원
→
기울어진 원
```

---

## Step 2 — $(\Sigma$)

각 축 방향으로 다르게 늘리거나 줄인다.

```text
기울어진 원
→
기울어진 타원
```

이 단계에서 실제 형태 변화가 발생한다.

---

## Step 3 — $(U$)

마지막으로 다시 회전한다.

```text
기울어진 타원
→
최종 타원
```

즉:

- $(V^T$): 입력 방향 정렬
- $(\Sigma$): 형태 변화
- $(U$): 최종 방향 설정

---

# 🌟 왜 SVD가 중요한가?

SVD는 다음 특징 때문에 매우 강력하다.

- 모든 실수 행렬은 항상 SVD를 가진다.
- 정방행렬이 아니어도 가능
- 역행렬이 없어도 가능
- rank deficient 행렬도 가능
- 수치적으로 매우 안정적

즉:

```text
가장 일반적이고 안정적인 행렬 분해 방법
```

이다.

---

# 📌 SVD는 어디에 쓰일까?

## 1️⃣ PCA (차원 축소)

데이터가 가장 많이 퍼진 방향을 찾는다.

- 데이터 압축
- 노이즈 제거
- feature extraction

---

## 2️⃣ 이미지 압축

큰 특이값만 남기고 작은 특이값 제거

→ 원본과 거의 비슷한 이미지를 훨씬 적은 데이터로 표현 가능

---

## 3️⃣ 추천 시스템

사용자–아이템 행렬 분해

- 넷플릭스
- 유튜브
- 쇼핑 추천

등에서 사용

---

## 4️⃣ 최소제곱(Least Squares)

해가 없거나 너무 많은 경우에도 가장 그럴듯한 해를 구할 수 있다.

---

## 5️⃣ Curve fitting

노이즈가 있는 데이터에서도 가장 안정적인 fitting 가능

---

# Curve Fitting과 SVD

# 🎯 Curve fitting 문제

예를 들어 직선:

```math
y = ax + b
```

를 데이터에 fitting한다고 하자.

데이터:

```text
(1, 2)
(2, 3)
(3, 5)
(4, 4)
```

---

# 🧩 행렬 형태로 만들기

```math
A =
\begin{bmatrix}
1 & 1 \\
2 & 1 \\
3 & 1 \\
4 & 1
\end{bmatrix}
```

```math
x =
\begin{bmatrix}
a \\
b
\end{bmatrix}
```

```math
y =
\begin{bmatrix}
2 \\
3 \\
5 \\
4
\end{bmatrix}
```

우리가 원하는 것은:

```math
Ax \approx y
```

를 만족하는 $(x$) 이다.

---

# 📉 최소제곱 문제

실제 데이터는 보통 완벽한 직선 위에 있지 않다.

그래서 다음 오차를 최소화한다.

```math
\min_x ||Ax - y||^2
```

이것이 최소제곱(least squares) 문제이다.

---

# 🔍 왜 SVD를 사용하는가?

고전적인 방법:

```math
x = (A^T A)^{-1} A^T y
```

하지만 이 방식은:

- 수치적으로 불안정
- 거의 singular인 경우 매우 위험
- 노이즈 증폭 가능

문제가 있다.

---

# SVD를 이용한 최소제곱 해

먼저:

```math
A = U \Sigma V^T
```

로 분해한다.

그 다음:

```math
A^+ = V \Sigma^+ U^T
```

를 만든다.

여기서:

- $(A^+$): pseudoinverse(의사역행렬)
- $(\Sigma^+$): 특이값 역수 행렬

즉:

```math
\sigma_i \rightarrow \frac{1}{\sigma_i}
```

로 바꾸는 것이다.

---

# 최소제곱 해

최소제곱 해는:

```math
x = A^+ y
```

즉:

```math
x = V \Sigma^+ U^T y
```

이다.

---

# 🧠 기하적 의미

## $(U^T y$)

$(y$) 를 $(U$) 가 정의하는 직교 좌표계로 변환

---

## $(\Sigma^+$)

각 방향의 중요도에 따라 scaling

- 큰 특이값 방향 → 안정적
- 작은 특이값 방향 → 노이즈 증폭 가능

---

## $(V$)

계산된 결과를 원래 parameter space 방향으로 복원

---

# ⚠ 작은 특이값이 위험한 이유

작은 특이값에 대해:

```math
\frac{1}{\sigma_i}
```

는 매우 커질 수 있다.

즉:

- 작은 노이즈도 크게 증폭됨
- fitting이 흔들림
- 과적합 발생 가능

---

# 🎯 자유도 감소(Dimension Reduction)

작은 특이값을 제거하면:

```math
\sigma_i \rightarrow 0
```

즉:

- 중요하지 않은 방향 제거
- 노이즈 제거
- 자유도 감소
- 더 안정적인 fitting

이 가능해진다.

---

# 🌟 직관적인 비유

3차원 데이터가 실제로는 거의 어떤 평면 위에 있다고 생각해보자.

SVD는:

1. 데이터를 회전시켜 중요한 방향 정렬
2. 실제 정보가 거의 없는 축 발견
3. 그 축 제거

를 수행한다.

즉:

```text
3D 데이터를
실제로 의미 있는 2D 평면 위로 눕히는 느낌
```

이다.

Curve fitting에서는:

```text
실제로 필요한 자유도만 남기고
나머지 노이즈 방향은 제거
```

하는 과정이라고 이해하면 된다.

---

# 📌 Curve fitting에서 SVD를 쓰는 이유

| 이유 | 설명 |
|---|---|
| 수치적으로 안정적 | ill-conditioned 문제에서도 안정적 |
| 노이즈에 강함 | 작은 특이값 제거 가능 |
| 자유도 조절 가능 | rank reduction 가능 |
| 해가 없어도 가능 | pseudoinverse 사용 |
| 모든 행렬 가능 | 정방행렬 필요 없음 |
| 데이터 구조 반영 | principal direction 추출 |

---

# 🎉 전체 요약

SVD는:

```math
A = U \Sigma V^T
```

로 모든 선형변환을:

```math
회전
\rightarrow
스케일 변화
\rightarrow
다시 회전
```

으로 분해하는 방법이다.

Curve fitting에서는:

```math
x = V \Sigma^+ U^T y
```

를 사용하여:

- 가장 안정적인 최소제곱 해를 구하고
- 노이즈를 줄이며
- 자유도를 조절하고
- 실제 데이터가 존재하는 방향만 사용

할 수 있다.

즉 SVD는:

```text
데이터에서
정말 중요한 방향만 남기는 방법
```

이라고 볼 수 있다.

---
## 소스 코드
```cpp

void maths::on_svdcmp(Matrix& a, TArrayD& w, Matrix& v)
{
    const int rows = a.RowCount();
    const int cols = a.ColCount();

    int ix1 = 0;
    int ix2 = 0;

    TArrayD rv1(cols);
    w.SetSize(cols);
    v.Create(cols, cols);

    for (int i = 0; i < cols; ++i)
    {
        rv1[i] = 0.0;
        w[i] = 0.0;
        for (int j = 0; j < cols; ++j)
            v[i][j] = 0.0;
    }

    double anrm = 0.0;
    double sca1 = 0.0;
    double sca2 = 0.0;

    for (int i = 0; i < cols; ++i)
    {
        ix1 = i + 2;
        rv1[i] = sca1 * sca2;

        double s1 = 0.0;
        double s2 = 0.0;
        double g = 0.0;

        if (i < rows)
        {
            for (int j = i; j < rows; ++j)
                s1 += fabs(a[j][i]);

            if (s1 != 0.0)
            {
                for (int k = i; k < rows; ++k)
                {
                    a[k][i] /= s1;
                    s2 += a[k][i] * a[k][i];
                }

                double f = a[i][i];
                g = -on_absolute(sqrt(s2), f);

                double h = f * g - s2;
                a[i][i] = f - g;

                for (int k = ix1 - 1; k < cols; ++k)
                {
                    double s = 0.0;
                    for (int l = i; l < rows; ++l)
                        s += a[l][i] * a[l][k];

                    double f2 = s / h;
                    for (int l = i; l < rows; ++l)
                        a[l][k] += f2 * a[l][i];
                }

                for (int k = i; k < rows; ++k)
                    a[k][i] *= s1;
            }
        }

        w[i] = s1 * g;

        sca1 = 0.0;
        double s3 = 0.0;
        sca2 = 0.0;

        if (i + 1 <= rows && i + 1 != cols)
        {
            for (int j = ix1 - 1; j < cols; ++j)
                sca1 += fabs(a[i][j]);

            if (sca1 != 0.0)
            {
                for (int k = ix1 - 1; k < cols; ++k)
                {
                    a[i][k] /= sca1;
                    s3 += a[i][k] * a[i][k];
                }

                double f = a[i][ix1 - 1];
                sca2 = -on_absolute(sqrt(s3), f);

                double h = f * sca2 - s3;
                a[i][ix1 - 1] = f - sca2;

                for (int k = ix1 - 1; k < cols; ++k)
                    rv1[k] = a[i][k] / h;

                for (int l = ix1 - 1; l < rows; ++l)
                {
                    double s = 0.0;
                    for (int m = ix1 - 1; m < cols; ++m)
                        s += a[l][m] * a[i][m];

                    for (int m = ix1 - 1; m < cols; ++m)
                        a[l][m] += s * rv1[m];
                }

                for (int l = ix1 - 1; l < cols; ++l)
                    a[i][l] *= sca1;
            }
        }

        anrm = (std::max)(anrm, fabs(w[i]) + fabs(rv1[i]));
    }

    for (int i = cols - 1; i >= 0; --i)
    {
        if (i < cols - 1)
        {
            if (sca2 != 0.0)
            {
                for (int j = ix1; j < cols; ++j)
                    v[j][i] = a[i][j] / a[i][ix1] / sca2;

                for (int j = ix1; j < cols; ++j)
                {
                    double s = 0.0;
                    for (int k = ix1; k < cols; ++k)
                        s += a[i][k] * v[k][j];

                    for (int k = ix1; k < cols; ++k)
                        v[k][j] += s * v[k][i];
                }
            }

            for (int j = ix1; j < cols; ++j)
                v[i][j] = v[j][i] = 0.0;
        }

        v[i][i] = 1.0;
        sca2 = rv1[i];
        ix1 = i;
    }

    for (int i = (std::min)(rows, cols) - 1; i >= 0; --i)
    {
        int i1 = i + 1;
        double g = w[i];

        for (int j = i1; j < cols; ++j)
            a[i][j] = 0.0;

        if (g != 0.0)
        {
            double ig = 1.0 / g;

            for (int k = i1; k < cols; ++k)
            {
                double s = 0.0;
                for (int l = i1; l < rows; ++l)
                    s += a[l][i] * a[l][k];

                double f = s / a[i][i] * ig;
                for (int l = i; l < rows; ++l)
                    a[l][k] += f * a[l][i];
            }

            for (int j = i; j < rows; ++j)
                a[j][i] *= ig;
        }
        else
        {
            for (int j = i; j < rows; ++j)
                a[j][i] = 0.0;
        }

        ++a[i][i];
    }

    for (int i = cols - 1; i >= 0; --i)
    {
        for (int it = 0; it < 30; ++it)
        {
            bool split = true;
            int k = 0;

            for (k = i; k >= 0; --k)
            {
                ix2 = k - 1;

                if (fabs(rv1[k]) + anrm == anrm)
                {
                    split = false;
                    break;
                }

                if (fabs(w[ix2]) + anrm == anrm)
                    break;
            }

            if (split)
            {
                double c = 0.0;
                double s = 1.0;

                for (int l = k; l < i + 1; ++l)
                {
                    double f = s * rv1[l];
                    rv1[l] = c * rv1[l];

                    if (fabs(f) + anrm != anrm)
                    {
                        double g = w[l];
                        double h = on_distance(f, g);
                        w[l] = h;

                        double ih = 1.0 / h;
                        c = g * ih;
                        s = -f * ih;

                        for (int m = 0; m < rows; ++m)
                        {
                            double y = a[m][ix2];
                            double z = a[m][l];
                            a[m][ix2] = y * c + z * s;
                            a[m][l] = z * c - y * s;
                        }
                    }
                    else
                    {
                        break;
                    }
                }
            }

            double z = w[i];

            if (k == i)
            {
                if (z < 0.0)
                {
                    w[i] = -z;
                    for (int j = 0; j < cols; ++j)
                        v[j][i] = -v[j][i];
                }
                break;
            }

            if (it == 29)
                return;

            double x = w[k];
            ix2 = i - 1;
            double y = w[ix2];
            double g = rv1[ix2];
            double h = rv1[i];

            double f = ((y - z) * (y + z) + (g - h) * (g + h)) /
                (2.0 * h * y);

            double q = on_distance(f, 1.0);

            double t = ((x - z) * (x + z) +
                 h * (y / (f + on_absolute(q, f)) - h)) / x;

            double c = 1.0;
            double s = 1.0;

            for (int l = k; l <= ix2; ++l)
            {
                int l1 = l + 1;
                double g2 = rv1[l1];
                double y2 = w[l1];

                double f2 = s * g2;
                double g3 = c * g2;

                double z2 = on_distance(t, f2);
                rv1[l] = z2;

                c = t / z2;
                s = f2 / z2;

                double f3 = x * c + g3 * s;
                double g4 = g3 * c - x * s;
                double h2 = y2 * s;
                double y3 = y2 * c;

                for (int m = 0; m < cols; ++m)
                {
                    double x2 = v[m][l];
                    double z3 = v[m][l1];
                    v[m][l] = x2 * c + z3 * s;
                    v[m][l1] = z3 * c - x2 * s;
                }

                double z4 = on_distance(f3, h2);
                w[l] = z4;

                if (z4 != 0.0)
                {
                    double iz = 1.0 / z4;
                    c = f3 * iz;
                    s = h2 * iz;
                }

                t = c * g4 + s * y3;
                x = c * y3 - s * g4;

                for (int m = 0; m < rows; ++m)
                {
                    double y4 = a[m][l];
                    double z5 = a[m][l1];
                    a[m][l] = y4 * c + z5 * s;
                    a[m][l1] = z5 * c - y4 * s;
                }
            }

            rv1[k] = 0.0;
            rv1[i] = t;
            w[i] = x;
        }
    }
}
```
